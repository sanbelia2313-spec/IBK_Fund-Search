② 신탁계약서(집합투자규약서) 펀드영업일구분 자동추출용
📑
신탁계약서 PDF를 끌어다 놓거나 클릭
"영업일"이라 함은 ~ 정의 조항에서 펀드영업일구분을 판단해요
페이지 읽는 중…
사용 순서
1. 투자설명서 업로드 → 상품명·상품공통정보(위험등급/운용회사/매수일수/환매체결·결제일수)가 자동으로 채워져요
2. 신탁계약서 업로드 → 펀드영업일구분(당사영업일/증권거래소/해외영업일)이 자동으로 판단돼요
3. 클래스 코드는 클래스 선택 표에서 클릭해서 확정
4. 값이 이상하면 칸을 직접 클릭해서 수정 (칸 아래 기울임체는 못 찾은 항목)

운용사마다 매입/환매방법, "영업일" 정의 표현이 달라 100% 정확하진 않아요. 못 찾았거나 값이 틀렸으면 가운데 원문 탭을 바꿔서 "매입방법", "환매방법", "영업일"을 직접 검색해 고쳐주세요.

색상 안내 — 필수기입사항: 노란색(값이 채워져도 계속 노란색 유지) · 그 외 전부: 흰색

추출된 원문 (검증용 — 못 찾은 항목 확인할 때만 사용)

PDF를 업로드하면 여기에 전체 텍스트가 표시됩니다.
